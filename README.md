# Site statique KAROUI — prêt pour GitHub Pages

## Structure
- `index.html` : accueil
- `entreprise.html` : présentation de l’entreprise
- `savoir-faire.html` : métiers et méthodologie
- `references.html` : références sélectionnées
- `moyens-qualifications.html` : Qualibat, formations, moyens matériels
- `contact.html` : coordonnées et formulaire `mailto:` sans serveur
- `404.html` : page d’erreur
- `assets/` : CSS, JavaScript et images

## Publication sur GitHub Pages
1. Créer un dépôt GitHub, par exemple `karoui-site`.
2. Importer **tout le contenu de ce dossier à la racine du dépôt**.
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. GitHub affichera l’adresse publique après le déploiement.

## Formulaire de contact
Le site est 100 % statique. Le formulaire de la page Contact ouvre le logiciel de messagerie du visiteur avec un e-mail prérempli vers `contact@karoui.fr`.

Si vous souhaitez plus tard un envoi directement depuis le site sans ouvrir le logiciel de messagerie, il faudra connecter un service de formulaire (Formspree, Web3Forms, etc.) ou un backend.

## À vérifier avant mise en ligne
- validation finale des textes par KAROUI ;
- confirmation que les qualifications/certificats sont toujours valides au jour de publication ;
- remplacement éventuel des visuels d’illustration par de vraies photos de chantiers autorisées ;
- ajout des mentions légales et d’une politique de confidentialité si des outils de suivi ou un formulaire tiers sont ajoutés.
